# Comercial El Buen Precio S.A. - Frontend demo

Demo frontend estática para una tienda de productos electrónicos. No contiene backend, base de datos ni APIs reales; todos los datos viven en archivos mock dentro de `src/data`.

## Ejecutar localmente

Desde esta carpeta:

```powershell
python -m http.server 4173
```

Luego abrir:

```text
http://127.0.0.1:4173/
```

Rutas disponibles:

- `/`
- `/tienda`
- `/carrito`
- `/mi-cuenta/pedidos/EBP-2026-0012`
- `/admin/dashboard`
